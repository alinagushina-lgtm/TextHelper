# TextHelper

Помощник для обработки текста, живёт иконкой в системном трее Windows.
Работает через Claude Code в headless-режиме — по подписке, без API-ключа.

Техническое задание: [TextHelper-ТЗ.md](TextHelper-ТЗ.md)

## Что нужно

- Windows 10/11
- Python 3.10 или новее
- Claude Code с выполненным входом в аккаунт (проверить: `claude --version`, при необходимости `claude login`)

## Установка

```bash
pip install -r requirements.txt
```

Затем один раз создайте ярлык на рабочем столе:

```bash
python create_shortcut.py
```

И один раз скачайте модель распознавания речи для голосового ввода (~25 МБ):

```bash
python install_speech.py
```

## Запуск

Двойной клик по ярлыку **TextHelper** на рабочем столе. Приложение стартует и сразу
показывает панель со списком действий, а значок приложения появляется в трее.

Вместе с Windows приложение не запускается — только вручную.

Из командной строки то же самое:

```bash
pythonw texthelper.py
```

## Как пользоваться

1. Выделите текст в любой программе — в Word, браузере, почте. `Ctrl+C` нажимать не нужно,
   приложение скопирует выделенное само
2. Нажмите кнопку на панели, которая висит в правом верхнем углу поверх всех окон
   (или выберите действие в меню иконки ✦ в трее)
3. Пока иконка показывает песочные часы ⏳ — идёт обработка, она занимает 6–8 секунд
4. В окне появятся «БЫЛО» и «СТАЛО»

Если выделения нет, приложение возьмёт то, что лежит в буфере обмена. Если пусто и там —
подскажет на панели.

## Перевод с картинки

Кнопки перевода работают не только с текстом, но и с изображением:

1. Нажмите `Win + Shift + S` и выделите кусок экрана — снимок попадёт в буфер обмена
   (либо скопируйте файл фотографии в проводнике)
2. Нажмите «Переведи на русский» или «Переведи на английский»

Claude сам прочитает текст с картинки и переведёт его. Это занимает 12–13 секунд —
дольше, чем обычный текст. Результат можно так же дорабатывать: «сделай короче».

Остальные действия работают только с текстом. Чтобы разрешить картинки ещё какому-то
действию, добавьте ему в настройках строку `"images": true`.

Панель можно закрыть, приложение останется в трее. Вернуть её — пункт «✦ Меню действий»
в меню иконки или повторный клик по ярлыку на рабочем столе. Второй копии приложения при
этом не появится.

**Не видно значок в трее?** Windows прячет все новые значки в скрытую область. Нажмите
стрелку `^` слева от часов — значок (профессор с высунутым языком на фиолетовом фоне)
будет там. Чтобы она всегда была на виду, перетащите
её мышью на панель задач. Пользоваться приложением можно и без этого — через окно действий,
которое открывается при запуске.

Дальше можно:
- нажать «Скопировать» и вставить результат куда нужно;
- написать уточнение («сделай ещё короче», «добавь деталей») и нажать «Отправить»;
- закрыть окно клавишей `Esc`.

## Голосовой ввод

Уточнение можно не печатать, а сказать вслух:

1. Нажмите кнопку **«Голос»** рядом с полем уточнения
2. Скажите, что поправить — «сделай ещё короче», «добавь деталей»
3. Нажмите **«Стоп»** — через пару секунд текст появится в поле
4. «Отправить»

Речь распознаётся на вашем компьютере, без интернета: ничего никуда не отправляется.
Настраивать что-либо в Windows не нужно.

## Свои действия

Кнопка «Настройки» внизу панели (или пункт «⚙️ Настройки» в меню трея) открывает файл
настроек в «Блокноте». После сохранения и закрытия «Блокнота» список действий обновляется
сам — перезапуск не нужен.

```
%LOCALAPPDATA%\TextHelper\settings.json
```

Чтобы добавить своё действие, допишите объект в массив `actions`:

```json
{
  "title": "📝 Составь план",
  "prompt": "Преврати текст в структурированный план по пунктам."
}
```

Там же настраиваются модель (`model`), таймаут (`timeout_seconds`) и предельная длина
текста (`max_input_chars`).

## Если что-то пошло не так

Лог работы:

```
%LOCALAPPDATA%\TextHelper\texthelper.log
```

## Состав проекта

| Файл | Назначение |
|---|---|
| `texthelper.py` | иконка в трее, меню, вызов Claude Code, настройки |
| `ui.py` | панель действий, окно «БЫЛО → СТАЛО», служебные окна |
| `speech.py` | запись с микрофона и распознавание речи |
| `create_shortcut.py` | создание ярлыка на рабочем столе, запускается один раз |
| `install_speech.py` | загрузка модели распознавания речи, запускается один раз |
| `settings.default.json` | действия по умолчанию |
| `requirements.txt` | зависимости: pystray, pillow, pyperclip, sherpa-onnx, sounddevice, numpy |
