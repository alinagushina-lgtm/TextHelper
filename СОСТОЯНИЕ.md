# Где мы остановились

Заметка на 13 августа 2026. Чтобы вернуться к работе, не перечитывая всю переписку.

## Коротко

Приложение **TextHelper** написано, работает и проверено вживую. Техническое задание
[TextHelper-ТЗ.md](TextHelper-ТЗ.md) готово к отправке преподавателю и соответствует тому,
что реально работает.

## Как запустить

Двойной клик по ярлыку **TextHelper** на рабочем столе. Приложение появляется панелью
в правом верхнем углу поверх всех окон.

Дальше: выделяете текст в любой программе → жмёте кнопку на панели → окно «БЫЛО → СТАЛО».
Нажимать `Ctrl+C` не нужно, приложение копирует выделенное само.

Закрыть — «Выход» внизу панели.

## Что готово и проверено

- Обработка выделенного текста через Claude Code по подписке, без API-ключа
- Доработка результата с сохранением контекста — главный баг из демонстрации преподавателя закрыт
- Голосовой ввод уточнений: кнопка «Голос», распознавание на компьютере, без интернета
- Панель поверх всех окон, ярлык на рабочем столе, защита от запуска второй копии
- Кнопка «Скопировать», обработка пустого буфера, лог работы
- Свой значок: профессор с высунутым языком на фиолетовом фоне
- Синяя тема во всех окнах

## Что осталось непроверенным

Мелочи, которые видно только руками:

- «Настройки» → дописать пятое действие в JSON → проверить, что оно появилось на панели
- «Выход» на панели и в меню трея
- Меню по клику на значке в трее (значок прячется в скрытой области под стрелкой `^`)

## Возможные следующие шаги

Ничего из этого не обязательно — приложение законченное.

- Подправить синюю тему: насыщенность фона, контраст полей «БЫЛО»/«СТАЛО»
- Добавить кнопку «Голос» на панель, чтобы диктовать не только уточнения
- Отсечение повторов в распознанной речи, если будет мешать
